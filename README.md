# my-niro

מעקב חי אחרי קיה נירו ונירו פלוס יד שנייה בישראל, שנתון **2022 ומעלה בלבד**.
כל מודעה מגיעה עם ק״מ מדויק, פרטי מוכר וטלפון, חישוב אחריות סוללה, עלות אנרגיה
שנתית והערכת עלות ל-5 שנים. אפשר לסנן, למיין, ולכתוב הערה אישית על כל רכב.

## הרצה מקומית

```bash
npm install
npm run dev
```

הדפדפן: http://localhost:3000

## פריסה ל-Vercel

1. `git push` לריפו הזה.
2. ב-Vercel: **Add New → Project → Import** את `itay1313/my-niro`.
3. Framework מזוהה אוטומטית כ-Next.js. לוחצים **Deploy**. זהו, האתר עולה.

## הערות: איפה הן נשמרות

האתר עובד משתי דרכים, בלי הגדרות ובעם:

| מצב | מתי | התנהגות |
| --- | --- | --- |
| `local` | אין `POSTGRES_URL` | ההערות נשמרות ב-localStorage של הדפדפן. עובד מיד, לא עובר בין מכשירים. באתר מופיעה הודעה. |
| `postgres` | יש `POSTGRES_URL` | ההערות נשמרות בענן וזמינות מכל מכשיר. הטבלה נוצרת לבד בפעם הראשונה. |

### לחבר מסד נתונים

1. בפרויקט ב-Vercel: **Storage → Create Database → Postgres** (Neon).
2. **Connect** לפרויקט. Vercel מזריק את `POSTGRES_URL` אוטומטית.
3. **Redeploy**. הטבלה `listing_notes` נוצרת בקריאה הראשונה.

הקוד מקבל גם `DATABASE_URL` או `POSTGRES_PRISMA_URL`, כך שכל ספק Postgres יעבוד.

## איך מעדכנים את הנתונים

כל הנתונים יושבים בקובץ אחד: [`data/listings.json`](./data/listings.json).
אין מסד נתונים לרכבים ואין scraping בזמן ריצה, בכוונה: זה שומר על האתר מהיר
ועל ההיסטוריה ב-git.

לעדכון:

1. מוסיפים, עורכים או מסמנים `"status": "sold"` בקובץ.
2. קומיט ופוש.
3. Vercel בונה מחדש לבד.

### מבנה מודעה

```jsonc
{
  "id": "8uo4wgev",              // מזהה יד2, גם הלינק וגם מפתח ההערות
  "model": "נירו פלוס",
  "trim": "LX",
  "powertrain": "phev",          // phev | ev
  "year": 2023,                  // 2022 ומעלה. שנתון נמוך יותר מסונן החוצה
  "km": 99000,
  "hand": 1,
  "price": 87800,                // null אם לא צוין מחיר
  "negotiatedPrice": 82000,      // אופציונלי, מחיר שסוכם בטלפון
  "sellerType": "dealer",        // dealer | private
  "sellerName": "סאן-קאר",
  "contact": "נטע",
  "phones": ["053-5552175"],
  "area": "ירושלים",
  "postedAt": "2026-04-30",
  "status": "active",            // active | sold
  "highlight": "top",            // top | watch | caution | none
  "flags": ["התחייבות בבדיקה"],
  "claudeNote": "הערת ניתוח שמופיעה בכרטיס"
}
```

`claudeNote` היא הערת הניתוח שנכתבת יחד עם הנתונים. ההערות שאתה כותב באתר
נשמרות בנפרד ולא נדרסות בעדכון.

## מה מחושב אוטומטית

- **אחריות סוללה שנותרה** — פלאג-אין עד 200,000 ק״מ או 10 שנים, חשמלי עד
  150,000 ק״מ או 7 שנים, לפי המוקדם. מוצג בשנים לפי הנסועה בהנחות.
- **עלות אנרגיה שנתית** — לפי בנזין 95 בשירות עצמי וחשמל ביתי.
- **עלות משוערת ל-5 שנים** — פחת משוער ועוד אנרגיה ותחזוקה. מספר להשוואה בין
  שורות, לא תחזית.

ההנחות יושבות ב-`data/listings.json` תחת `assumptions` וניתן לשנות אותן שם.
